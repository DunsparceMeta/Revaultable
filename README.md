# Revaultable 
Revaultable is a datapack that tweaks how the vaults inside Trial Chambers work. It makes it so vaults re-open for the player if they are holding the appropriate key and looking at them.

I always thought it was weird the the spawners in trial chambers reset, meaning you can collect keys forever, but the vaults are one-time use. I first experienced this on a multiplayer server with my friends, where one of my friends had already done the chamber and came with me and my wife for a 2nd run. The chamber dropped 3 keys in each section, but my friend wasn't able to use any of her keys because she had already opened all the vaults. I made this datapack to solve that issue, since I think that trial chambers are a great way to introduce good, renewable loot that has a significant challenge attached to it.

Hopefully this pack will be temporary, and Mojang will make it so this becomes default behavior, but until them enjoy my pack! I'll try and keep it updated and might backport it to previous versions.
